# VideoJuego DiegoKong
Proyecto academico realizado mediante el lenguaje Java - ant
El cual se realizado para analizar los principos SOLID + Diseños de Patrones.
----------------------------
El proyecto cuenta con varios Diseños de patrones Estructurales , Creacionales y de Comportamiento
Comportamiento : Observer , State , Stratregy , TemplateMethod
Creacionales: Builder , Factory , Singleton
Estructurales: Adapter, Composite , Facade
